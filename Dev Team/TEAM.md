# Delivery Squad

> 团队创建日期：2026-07-07

## 团队宗旨

围绕 openagent 项目，建立一支多功能交付团队，涵盖从架构设计到文档撰写的完整研发链路。

## 角色说明

### 🏛️ 架构师
- 负责整体技术架构与模块划分
- 评估技术方案的可行性与风险
- 主导关键技术决策与评审

### 💻 开发工程师
- 按架构设计实现功能模块
- 遵循项目代码风格（tab 缩进、双引号、分号、行宽 100）
- 编写可维护、可测试的代码

### 🧪 测试工程师
- 设计测试用例，覆盖正常路径与边界条件
- 执行 `bun test` 并确保通过
- 监控代码质量指标

### 🔧 运维工程师
- 维护 CI/CD 流水线（lefthook + biome）
- 管理发布流程与版本号
- 监控运行时健康状态

### 📝 技术文档工程师
- 撰写和更新技术规格（openspec/specs/）
- 维护 API 文档与用户指南
- 记录架构决策与变更历史

### 🔍 代码审查员
- 审查 PR，确保代码风格与质量
- 追踪技术债务并提出改进建议
- 推广最佳实践与设计模式

---

## 协作原则

1. **开放沟通** — 所有关键决策留有记录，避免口头约定
2. **质量优先** — `bun run check` 必须通过，不绕过钩子
3. **持续改进** — 定期回顾流程，优化协作方式
4. **尊重规范** — 遵循 AGENTS.md 中的开发流程与代码风格
